# 원형 관계도 메이커 (Circle Relationship Diagram Maker)

이미지 업로드형 원들을 원형으로 배치하고, 원끼리 색깔 있는 선(화살표 선택 가능)으로 연결해
"CP망", "관계도" 같은 이미지를 만드는 정적 웹앱입니다. 빌드 과정 없이 GitHub Pages에 바로 올릴 수 있습니다.

## 주요 기능

- 원 개수 2 ~ 30개까지 슬라이더/입력으로 조절
- 각 원을 클릭해 원하는 이미지를 직접 업로드
- 원과 원을 선으로 연결, 선 색상 자유 선택 + 상단 범례에 색상 의미 기재
- 선 끝에 화살표 추가 가능 (단방향/양방향)
- 원 테두리는 기본 없음 → 필요 시 켜고 색상 지정, 역시 상단 범례에 의미 기재 가능
- 작업 내용을 JSON 파일로 저장 / 불러오기 (이미지까지 포함되어 나중에 이어서 편집 가능)
- 완성한 다이어그램을 고화질 PNG(2x/3x/4x)로 다운로드

## 로컬에서 열어보기

빌드 과정이 없는 순수 정적 사이트라 `index.html`을 그대로 브라우저로 열어도 되지만,
파일 업로드/저장 기능이 브라우저 보안 정책상 `file://` 환경에서 막히는 경우가 있으니
간단한 로컬 서버로 여는 걸 추천합니다.

```bash
# 이 폴더에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## GitHub Pages로 배포하기

1. 새 GitHub 저장소를 만듭니다 (예: `circle-diagram`).
2. 이 폴더(`index.html`, `style.css`, `app.js`, `assets/`)의 내용을 저장소 루트에 그대로 올립니다.
   ```bash
   git init
   git add .
   git commit -m "init: circle diagram maker"
   git branch -M main
   git remote add origin https://github.com/{your-id}/circle-diagram.git
   git push -u origin main
   ```
3. GitHub 저장소 → **Settings → Pages** 로 이동합니다.
4. **Source**를 `Deploy from a branch`로 두고, Branch를 `main` / `/ (root)`로 선택 후 저장합니다.
5. 잠시 뒤 `https://{your-id}.github.io/circle-diagram/` 주소로 접속하면 바로 사용할 수 있습니다.

## 사용 방법

1. **원 개수** 슬라이더로 원하는 인원 수(2~30)를 맞춥니다.
2. 원을 클릭하면 편집창이 열립니다. **이미지 업로드**로 캐릭터/인물 이미지를 등록하고,
   필요하면 **테두리 사용**을 켜고 색을 고릅니다. 아래쪽 이름표도 선택 입력할 수 있어요.
3. **선 연결 모드**를 켜고 원 A → 원 B 순서로 클릭하면 선 색상/화살표를 고르는 창이 뜹니다.
4. 왼쪽 **선 색상 의미**, **테두리 색상 의미** 목록에서 범례 문구를 자유롭게 적어두면
   다이어그램 상단에 자동으로 표시됩니다.
5. 다 만든 뒤 **JSON 저장**으로 백업해두면 나중에 **JSON 불러오기**로 이어서 수정할 수 있습니다.
6. **고화질 PNG로 저장**을 누르면 현재 화면 그대로 이미지 파일로 다운로드됩니다.
   (해상도 배율을 2x/3x/4x 중 선택 가능)

## 폴더 구조

```
circle-diagram/
├── index.html          # 페이지 구조
├── style.css            # 스타일
├── app.js                # 전체 로직 (상태 관리, 렌더링, 저장/내보내기)
├── assets/
│   └── html2canvas.min.js  # PNG 캡처용 라이브러리 (오프라인 번들)
└── README.md
```

외부 CDN 없이 `html2canvas`를 로컬 파일로 번들해두었기 때문에, GitHub Pages 배포 후에도
별도 네트워크 의존성 없이 그대로 동작합니다.

## 참고

- 이미지와 다이어그램 설정은 전부 **브라우저 안에서만** 처리됩니다. 서버로 전송되지 않으니
  JSON 파일로 저장해서 직접 보관하세요.
- 업로드한 이미지는 저장 용량을 줄이기 위해 자동으로 최대 400px로 축소됩니다.
